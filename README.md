# ATLAS2 Follow NEO — גרסה 18

## הפעלה עם פרופיל ההגדרות המשותף

**הורדת ZIP בלבד אינה טוענת את הפרופיל.** כדי להשתמש בערכי הניסוי המשותפים:

1. הורידו וחלצו את ענף `yolo26s_integ_v18` המעודכן.
2. בהתקנה ראשונה, הריצו `SETUP_FOLLOW_NEO.cmd` והמתינו לסיום מוצלח.
3. סגרו את כל חלונות Follow NEO. האפליקציה שומרת הגדרות בסגירה, ולכן חלון ישן פתוח יכול לדרוס את הפרופיל החדש.
4. לחצו פעמיים על **[RUN_FOLLOW_NEO_V18_PROFILE.cmd](RUN_FOLLOW_NEO_V18_PROFILE.cmd)** מתוך התיקייה שחולצה.

הקובץ טוען את [הפרופיל המשותף](profiles/v18_shared.json), מגבה את ההגדרות הקיימות
ומפעיל את הממשק רק אחרי טעינה מוצלחת. כתובת הטלפון, בחירת העיבוד וכרטיס המסך נשמרים.
בהתקנה חדשה צריך להגדיר את הפרטים המקומיים בממשק. אין חיבור אוטומטי לרחפן או התחלת ריקוד.

**כל הפעלה דרך הקובץ החדש מחזירה את ערכי הפרופיל המשותף.** אחרי ששיניתם ערכים
לניסוי ורוצים להמשיך איתם, הפעילו דרך `RUN_FOLLOW_NEO.cmd`; הוא משתמש בהגדרות המקומיות השמורות.
אין להעתיק את `profiles/v18_shared.json` ישירות לשם `config.local.json` — כלי הטעינה מבצע את ההמרה.

| בדיקה בממשק | ערך צפוי לאחר טעינת הפרופיל |
|---|---|
| TCP Send rate | 25Hz |
| Forward / Back | 6% |
| Side L / R | 35.3% |
| Yaw L / R | 100% |
| Up / Down | 0% |
| GMC | 480×270, עד 400 נקודות |
| Settings — Nano | guarded |
| NanoTrack primary position (Dance) | מסומן |
| Model | neo_minipro4_yolo26s_seg_960x544_v6.onnx |

אם הטעינה נכשלת, חלון CMD נשאר עם השגיאה והאפליקציה אינה מופעלת.
הגיבוי נשמר תחת `backups/before_v18_profile_...` והנתיב מודפס בחלון.

הוספת קובץ ההפעלה אינה משנה את המעקב, TCP, מצב HARD, סף הבטיחות של 250ms או האנדרואיד.

להוראות המלאות, עדכון התקנה קיימת ושחזור הגדרות: **[המדריך בעברית](README_HE.md)**.
